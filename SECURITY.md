# Security Policy

Please report security-sensitive problems privately rather than opening a public issue.

Use GitHub's private security reporting channel for this repository when it is available. Otherwise, contact the repository maintainer privately through the associated GitHub account.

Include the affected revision, a concise description of the boundary involved, and enough information to reproduce the problem safely.

Issues involving policy-boundary enforcement, unsafe effect classification, persisted policy state, dependency integrity, or accidental promotion of non-authority output into runtime authority should be treated as security-sensitive.
